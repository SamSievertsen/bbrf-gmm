Analysis Overview

Goal is to discover latent daily states from a small set of continuous psychophysiological features (i.e., mood, actigraphy derived sleep, go/no-go cognition) by fitting a Gaussian Mixture Model via EM, then characterize those states by their suicidal-ideation profiles and analyze how individuals move among them over time.

This will occur in three stages.

  1. Univariate EM (EDA + code stepping-stone). Fit a 1-D GMM to each feature to inspect multimodality before committing to the joint model. We also run a pre-registered check on the go/no-go commission feature and document its eventual exclusion from the mixture
  2. Multivariate GMM (the model). Fit the joint mixture; select K by comparing BIC, AIC, and ICL (with classification entropy and the smallest mixing weight as degeneracy diagnostics), a Kneedle knee, a marginal density-fit comparison, and the person x state artifact check (never a single minimum)
  3. States + dynamics. Overlay SI/SB onto states; decode per-person state sequences; relate early-warning indicators (variance, lag-1 autocorrelation) to transitions into high-SI states
Modeling on 644 complete person-days across 30 subjects (of 813 total person-days). Modeling features: depression, anxiety, sleep_eff, hrs_to_sleep, sleep_totalmin.

Commission: documented exclusion check

Go/no-go commission-error rate is a theoretically central index of inhibitory control, and we retained it as a candidate state feature. But ~45% of person-days have zero commission errors (<=1 error on ~50 trials; see the floor share above), so the empirical-logit rate carries a point mass that a Gaussian component can only absorb by collapsing its variance. The check below fits the mixture with commission included and shows the consequence, i.e., commission dominates feature discrimination only by spawning near-zero-variance components anchored at the error-rate floor. In other words, it sorts days into “any errors vs none” rather than indexing graded control. On that pre-registered basis we exclude it from the mixture and retain it as a descriptive overlay on the mood/sleep states. The evidence is kept here for the writeup.

## Why commission is an overlay, not a mixture input ##

if ("commission_elogit" %in% feat) {

Limitations

  • Person-days are not independent (i.e., within-person autocorrelation; clustering in ~30 people); the GMM likelihood treats them as exchangeable, which inflates the effective N that BIC assumes and biases it toward more components. Mitigations: ICL (entropy-penalized) and the smallest-mixing-weight diagnostic alongside BIC, the person x state artifact check, and a planned person-mean-centered fit (person_center()) isolating within-person state structure.
  • Commission-error rate is excluded from the mixture (documented above: ~45% zero-error days force degenerate components) and reported as an overlay only.
  • The daily EMA mood items are depression and anxiety only – there is no daily elevated-mood/manic item – so states characterize the depressive/dysregulated axis, with the manic pole captured only indirectly (e.g., via sleep loss).
  • Actigraphy was processed with the Sadeh algorithm for most but not all participants; the algorithm is a one-line config swap for a Cole-Kripke sensitivity analysis.
  • If the criteria prefer K = 1 or states reduce to person identity, that is itself a reportable finding about the (lack of) shared multivariate state structure.
